Independent study and Python exercises for **Introduction to Computational Thinking and Data Science**.

Computational models, optimization and search, stochastic simulation, and data analysis. These are course themes, not a claim that all topics have been implemented in this directory.

Group code by problem set and keep required data files alongside the relevant exercises when redistribution is permitted. Read the assignment instructions for any third-party dependencies and expected working directory.

Implementations may include exploratory approaches and later revisions. Retain original notices in course-provided starter code.
