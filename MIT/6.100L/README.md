# MIT 6.100L

Independent study and Python programming exercises for **Introduction to CS and Programming using Python**.

## Focus

Python fundamentals, control flow, functions, strings and collections, decomposition, debugging, and computational problem-solving.

## Organization and Execution

Group related exercise files by problem set. Some exercises depend on accompanying course files; run them from their own problem-set directory and follow the original instructions. Retain attribution in any course-provided starter code.

This directory is a personal learning record rather than an official solution set.
