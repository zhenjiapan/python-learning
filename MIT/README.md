# MIT Coursework

Python exercises and independent study based on MIT OpenCourseWare.

## Courses

| Directory | Course |
| --- | --- |
| [6.100L](6.100L/) | Introduction to CS and Programming using Python |
| [6.0002](6.0002/) | Introduction to Computational Thinking and Data Science |

Exercises are organized by course and, where applicable, by problem set. The files present in each directory indicate the archived work; inclusion here does not imply completion of every assignment.

## Working with Exercises

Keep starter code, test files, and required datasets together when permitted. Run scripts from the relevant problem-set directory when they use relative file paths. Follow the original assignment instructions for inputs and dependencies.
