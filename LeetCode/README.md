# LeetCode Practice

Python solutions and revisions from my algorithm practice on [LeetCode](https://leetcode.com/).

## Organization

Organize solutions by their main topic, such as arrays and hashing, strings, two pointers, linked lists, stacks, prefix sums, or mathematics. Keep one primary copy of each solution; additional topics can be recorded in comments.

Recommended filename format: `0001-two-sum.py`. Existing filenames may differ.

## Documenting a Solution

Where useful, include:

- Problem number, title, and link.
- A brief explanation of the approach.
- Time and auxiliary space complexity for the actual implementation.
- Edge cases or lessons learned.

Complexity annotations should match the submitted code. For example, a double-loop solution to Two Sum has worst-case quadratic time; a hash-table implementation generally has expected linear time.

## Execution

Some files contain only the `Solution` class expected by LeetCode and will not produce output when run directly. Linked-list exercises may depend on platform-provided definitions such as `ListNode`. Use the platform or add an appropriate local driver to run these solutions.

## Scope

This is a learning archive, not a claim that every solution is optimal or independently executable. Problem statements and platform-provided code belong to their respective authors.
